## 멈춤 회귀 수정 포함 여부

- 최신 소스에서 시작/재시작 시 `physics.resume()`을 명시한다.
- 시작·재시작·일시정지·재개 때 탭 상태를 초기화해 버튼 탭이 오발 대시로 이어지지 않게 한다.
- 첫 플레이 탭은 점프, 285ms 안의 두 번째 탭은 대시, 대시 뒤 탭 쌍은 새로 소비한다.
- 백그라운드 전환 시 플레이를 자동정지하고, 복귀 후 자동 진행하지 않고 사용자 탭으로만 재개한다.
- APK 내 번들에서 `pauseGame`, `resumeGame`, `restart`, `잠시 멈췄어요`, `버튼을 눌러 계속` 문자열을 확인했다.

## 아직 필요한 API/서버 작업

- **온라인 주간 랭킹:** 현재 최고점은 로컬 저장뿐이며 Top100 서버 제출·조회·주간 초기화가 없다.
- **분석:** 세션 시작/완주/이탈, 장애물별 실패, 재시작, 미션·공유 전환 이벤트 수집이 없다.
- **치팅 방지:** 서버 검증 점수, 세션 nonce/서명, 리플레이 또는 입력 검증, 비정상 점수 탐지가 없다.

따라서 현재 Top100형 요소는 로컬 게임 루프·메타 진행에 한정되며, 온라인 경쟁 서비스로 출시 가능한 상태라고 판단하면 안 된다.
