## 최우선 회귀 수정

- 게임 종료 때 정지된 Arcade Physics가 장면 재시작 뒤에도 남아 첫 점프가 멈출 수 있는 경로를 수정했다. 모든 시작/재시작은 `physics.resume()`을 명시적으로 실행한다.
- 시작, 재시작, 수동 일시정지, 백그라운드 자동정지/복귀에서 탭 이력을 초기화한다.
- 시작/재개 버튼 탭이 다음 플레이 탭과 합쳐져 오발 대시가 되지 않도록 탭 상태기를 분리했다.
- 싱글탭 점프, 285ms 이내 더블탭 대시, 대시 뒤 새 탭 쌍 소비를 자동 회귀 검사한다.
- 복귀는 자동 진행하지 않고 정지 오버레이에서 사용자 탭으로만 재개한다.

## 로컬 Top100 지향 기능

- 500m, 명목 75.2초의 초·중·후반 속도 상승 곡선과 43개 공정 스폰을 유지했다.
- 장애물 연속 중복을 막고, 초반 8초는 점프 장애물만 제공하며 종류별 대응 힌트를 표시한다.
- 커피를 `+350점 / 급함 +6`의 명확한 위험-보상 선택으로 변경했다. 휴지는 급함을 낮춘다.
- 3개 일일 미션을 날짜별로 초기화하고 여러 판의 누적 진행을 HUD/시작 화면에 표시·저장한다.
- 미션 보상 코스메틱 해금과 선택, 최고점, 소리/진동 설정을 로컬 저장한다.
- 첫 사용자 안내에 점프/대시와 장애물 기호를 표시하고 확인 후 `seenTutorial`을 저장한다.
- 결과 등급/점수/휴지/콤보의 Web Share 또는 클립보드 복사를 제공한다.
- `prefers-reduced-motion`에서는 파티클과 화면 흔들림을 끄고, 렌더러는 low-power 및 30fps 하한/프레임 delta 상한을 유지한다.
- 외부 API, 광고, 결제, 로그인은 추가하지 않았다.

## 15시 전 실제 기기 확인 우선순위

1. 종료 후 `다시!` → 첫 점프가 즉시 작동하는지 10회 반복한다.
2. 시작/수동정지/홈 전환 복귀 직후 첫 탭은 점프, 빠른 두 탭은 대시인지 확인한다.

4. 날짜 변경 모의 또는 저장 초기화 뒤 미션 누적/해금/코스메틱 재실행 보존을 확인한다.
5. Android 공유 시트, 진동/소리 토글, 저사양 기기의 발열과 프레임 저하를 확인한다.
